# Teste de Interface (UI) — Amazon.com.br

## Objetivo

Verificar a consistência visual e funcional dos principais elementos de interface do site Amazon.com.br, identificando inconsistências de alinhamento, espaçamento, contraste e comportamento de componentes interativos.

## Escopo

**Incluso:**
- Barra de busca (posicionamento, placeholder, comportamento ao focar)
- Menu de navegação principal
- Botão de login/conta
- Dropdown "Contas e Listas"
- Alinhamento, espaçamento e contraste de elementos da home
- Banners e carrosséis (funcionamento, transição, responsividade visual)

**Fora de escopo:**
- Teste de acessibilidade formal (WCAG)
- Teste em múltiplas resoluções/dispositivos
- Teste funcional de compra
