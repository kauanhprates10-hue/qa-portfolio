# Teste Funcional — Busca e Filtros (Mercado Livre)

## Objetivo

Validar o comportamento da busca de produtos e dos filtros de refinamento no site Mercado Livre (mercadolivre.com.br), verificando se os resultados retornados correspondem aos critérios aplicados.

## Escopo

**Incluso:**
- Busca por termo (produto existente, inexistente, termo parcial)
- Aplicação de filtros (categoria, preço, condição, localização, frete grátis)
- Combinação de múltiplos filtros simultâneos
- Ordenação de resultados (relevância, menor/maior preço)

**Fora de escopo:**
- Processo de compra/checkout
- Teste de performance de carregamento
- Teste em aplicativo mobile
